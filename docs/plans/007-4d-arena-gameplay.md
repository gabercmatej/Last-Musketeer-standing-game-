## Decisions taken up front (log each in DECISIONS.md)
- **Walled edges** are a map property: `Board.EdgeWalls`. When true, `Board.Get(off-board)` returns `Pillar` instead of `Pit`, so moves, dashes, Bull Rush, keg kicks and pushes treat the edge as a pillar (a push into it = Wall Slam). Traces that already stop at `InBounds` (shots, Grappin, keg throws) keep stopping at the edge; the hook just misses at a wall. Map text directive: a first line `@walls` (MapParser skips `@` lines and sets the flag). Included in the board hash.
- **Bridge tiles (`b`)** are `Floor` in the sim (identical rules). `MapData.Bridges` (bool per tile) is presentation-only data parsed from the text. Crumble turns them into pit like any tile.
- **Dash (rule 1):** 2 tiles; only a **pillar on the middle tile** (or an off-board wall) blocks it. The landing tile must not be pillar/crate/keg (else `MoveBlocked Obstacle`, stay, Grit spent). The middle tile is flown over (crates, kegs, units, pits). For collisions a dash only **enters its landing tile**: it bonks on a shared landing tile, or on an exact swap (A lands on B's start while B lands on A's start). Walkers stepping into the middle tile, and units under the arc, never bonk with it. A unit on the landing tile that ends up not moving blocks it (Phase 2.3, no damage). Landing on a pit/off-board water = fall. `Leaped` is logged whenever the middle tile isn't empty floor (so playback can show the hop).
- **Switcheroo (rule 5):** `PlannedAction.Unit` (new byte field, the target slot) via `PlannedAction.Switcheroo(int slot)`. Range unlimited. Phase 2b in initiative order, using the target's position at that moment. Fails (Grit spent, `Swapped` with amount 0 and a reason) if Matic stands on a warned ring tile, the target is dead, or the target is Matic himself. No more keg swaps. Credit to Matic.
- **Triple Charge (rule 7):** `Ability.DoubleCharge` renamed `TripleCharge` (same byte value, so assets keep working); also `ShotKind`/`DamageKind`. Needs + spends the load in Phase 0. Phase 4 runs normal Fire shots exactly as today (snapshot, buffered, applied), **then** each Triple Charge in initiative order fires 3 shots **sequentially** on the live state: each traces from the shooter, range `FireRange` (5); a unit hit takes 1 damage and slides 1 tile away (normal push rules: wall slam, bonk, fall) with credit to the shooter; a crate is destroyed (the next shot can pass); a keg is marked detonating and stops the shot; a parrying unit takes no damage, isn't pushed, and reflects the shot like a normal reflection (1 damage to the first thing it meets on the way back, no push, not reflectable again). Config: `TripleChargeShots = 3`, `TripleChargePush = 1`; `DoubleChargeRange`/`DoubleChargePierce` removed.
- **Costs/knobs:** `SignatureCost = 5`, `BullRushPush = 4`, `PlanningSeconds = 30`. `MaxHp` (1–5, default 3) and `PointsToWin` (10–30, default 12) are set from the lobby via `MatchSetup.Config` (two steppers next to the map choice in the current lobby; 4C's lobby redesign keeps them; remembered in PlayerPrefs).
- **Crumble:** unchanged formula (ring = distance to the nearest edge). On 15×9, MaxRing = 4: ring 0 warned turn 5 / falls 6 … ring 3 falls turn 12 leaving the 7-tile center row, ring 4 falls turn 14 (draw). Verify with the fuzz summary.
- **Bridge map visuals:** all walkable tiles use the plank tile, rotated 90° on alternate squares (chess). `b` tiles use the same plank tile with planks across the walking direction and a darker trim along their water sides, so bridges read as bridges.
